# v1.0.5 — cfg 없는 가독성 폰트판

이 릴리스는 OpenMW 0.51의 사용자 `openmw.cfg`를 덮어쓰지 않습니다. Launcher에서 모드 폴더를 데이터 경로로 추가하고 기존 v1.0.4 ESP 하나만 활성화하면 됩니다.

주요 변경 사항:

- 기본 OpenMW 폰트 이름으로 제공되는 SmallBatang 보정 폰트
- 받침 유무 12px 고정 진행폭
- 종성·윗글자 세로 분리 및 초성 `ㅎ` 보정
- `CELL` 및 `PGRD` 레코드가 없는 최신 v1.0.4 ESP 유지

기존 `openmw.cfg`와 저장 파일을 덮어쓰지 마세요. 이전 한국어 ESP 및 시험용 폰트 모드는 중복 로드를 피하기 위해 비활성화해야 합니다.
